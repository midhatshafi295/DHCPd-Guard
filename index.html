DHCPd-Guard Security Architecture

Active
State-Aware DHCP Allocation

Tracks each client by MAC address and combines transaction state with current IP-pool pressure to decide whether a request is allowed, restricted, or denied.

Active
Pool-Pressure Monitoring

Classifies the active pool as LOW, MEDIUM, or HIGH pressure and applies the state-aware allocation policy when the pool becomes heavily used.

Active
Transaction State Tracking

Maintains NEW, PROBATION, STABLE, SUSPICIOUS, and QUARANTINED client states from DHCP transaction history.
